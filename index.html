Format d'exercice :

🌟

Mémo Grammatical : Tous les temps (Repérer les indices)

Indices : yesterday (passé) • right now (continu) • every day (présent) • tomorrow (futur)

Astuce clé : En anglais, regarde toujours le mot-indice de temps dans la phrase avant de conjuguer ! Par exemple, yesterday ou last week appelle le Passé Simple, tandis que right now appelle BE + -ING.

➕ Forme Affirmative
Présent : I work / She works • Passé : I worked / I went • Futur : I will work / I'm going to work
➖ Forme Négative
Présent : don't / doesn't + base • Passé : didn't + base • Futur : won't + base
❓ Forme Question
Présent : Do / Does + sujet + base ? • Passé : Did + sujet + base ? • Futur : Will + sujet + base ?
